What it is:
AGENTS.md is an open, plain-Markdown format that acts as a README for AI coding agents.
GitHub Copilot, VS Code, OpenAI Codex, and many other agent tools load it automatically
from the repository root.

Why it exists:
README.md is written for people. AGENTS.md holds the extra, agent-specific context
(build steps, test commands, conventions, gotchas) that would clutter the README.
One file serves every compatible agent, so guidance does not need to be duplicated per tool.

How to use it:
- There are no required fields or headings; the sections below are suggestions.
- Keep entries short and specific, and include the reason behind each rule.
- Prefer linking to README.md and .github/workflows/ci.yml over copying their content.
- Agents may read this whole file, including comments; write real guidance as plain Markdown outside comments.
- A chat prompt from the user overrides this file.
- Nested AGENTS.md files in subfolders are optional; the nearest one to the edited file wins.
- Treat this as living documentation and update it as the project changes.
